D2HA — release notes
// features

Updates, without surprises

A small, focused tool that does a few things very well — on the web and in Home Assistant.

🏷️

Real versions

Registry digests are checked with lightweight HEAD requests, so you see 13.2.5 → 13.3.0 — not just “something changed”.

📋

Release notes that match

The GitHub release of that exact version, with breaking changes highlighted before you update.

🛡️

Safe updates

The new image is pulled while the container keeps running; it is then recreated with your settings — and rolled back if it does not start.

📜

Live logs

Tail or follow the logs of any container, with search, coloured levels and download.

🏠

Home Assistant

An integration from Home Assistant's Marketplace (or HACS) brings update entities, container states and action buttons to your dashboards.

🔔

Telegram notifications

A message when an update appears — once per version, with the release-notes link and breaking-change warnings — when a container stops with an error or turns unhealthy, and never for a stop you asked for. Each kind can be turned off, and a label excludes a container.

🔐

Private by design

Sign-in with optional 2FA, no third-party requests from the browser, and a Docker socket proxy in the example setup.

// quick-start

Up and running in one minute

Copy the example compose file, start it, and sign in with the code from the logs. That’s it.

# get the example compose file and start d2ha
curl -O https://raw.githubusercontent.com/Arborae/docker2homeassistant/main/compose.example.yaml
mv compose.example.yaml compose.yaml
docker compose up -d
docker logs d2ha   # ← your one-time setup code

Then open http://localhost:12021, enter the setup code and create your account — the example includes a Docker socket proxy, so D2HA never touches the socket directly. On a server without a browser, open an SSH tunnel first (ssh -L 12021:localhost:12021 <user>@<server>), then that address works on your computer. Details in the installation guide.
